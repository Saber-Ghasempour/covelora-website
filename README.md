## DNS
CNAME: covelora -> Saber-Ghasempour.github.io
Use DNS-only mode if your DNS provider offers proxying while provisioning HTTPS.
Do not include a repository name or https:// in the DNS target.
After DNS propagates, enable Enforce HTTPS in repository Settings > Pages.
Confirm both the homepage and /privacy/ load over HTTPS before submitting the URL to Google Play.
The policy reflects the current code and should be reviewed when data practices change.
